# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

Karşılaştırmalı CSV dosyalarında Türkçe hedef alanını düzenleyin. Temiz mesaj/font girdileri kaynaklar altındadır. Denetim: python araclar/verify_package.py.

Düzenleme kaynağı: `ceviri/`.

Araç girişi: `araclar/msbt_batch_inject.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
