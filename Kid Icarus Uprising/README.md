# Kid Icarus Uprising Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `0004000000030200/` → `sd:/luma/titles/0004000000030200/`

## Çalışma dosyaları

Düzenleme kaynağı: `ceviri/tr/`.

Araç girişi: `araclar/msbt_bulk.py`. Komutları oyun klasöründe çalıştırın.

Diğer dil ve bölüm kaynakları ceviri ağacında korunmuştur. ZRC/LZ11 işlemleri için araclar/zrc_batch_lz11.py kullanılır.

## Klasörler

- `ceviri/`: Düzenlenecek çeviri verileri.
- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `belgeler/`: Kullanım ve teknik açıklamalar.
