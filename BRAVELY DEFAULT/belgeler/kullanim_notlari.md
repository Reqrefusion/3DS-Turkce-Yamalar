# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

Çeviri eşlemeleri Python veri modülleri ve araçların okuduğu JSON dosyaları içinde tutulur. Bunlar birlikte çalışan modüller olduğu için araclar altında korunmuştur. Bazı araştırma/üretim betikleri özgün harici girdileri gerektirir.

Düzenleme kaynağı: `araclar/translations_tr.py`.

Araç girişi: `araclar/prepare_layeredfs.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
