# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

İki Title ID hedefi vardır; cihazınızdaki başlık kimliğiyle eşleşeni kullanın. Temiz CXI/ZIP girdisiyle üretim ve verify_prebuilt.py ile doğrulama yapılır.

Düzenleme kaynağı: `ceviri/StgFace_all_languages_TR.csv`.

Araç girişi: `araclar/build_working_universal.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
