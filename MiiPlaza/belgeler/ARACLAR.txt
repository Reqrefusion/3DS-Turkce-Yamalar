araclar/mii_plaza_update_tr_tool.py
  Güncel Update Data içindeki BMSM dosyalarını çıkarma, 8 dili CSV'ye aktarma,
  placeholder doğrulama, Türkçe BMSM oluşturma ve LA4 fontlarını Türkçe gliflerle yamalama aracı.

Örnek:
  python araclar/mii_plaza_update_tr_tool.py extract miiplaza.zip --out romfs
  python araclar/mii_plaza_update_tr_tool.py export romfs --csv ceviri.csv
  python araclar/mii_plaza_update_tr_tool.py validate ceviri.csv
  python araclar/mii_plaza_update_tr_tool.py build romfs ceviri.csv --out patch --allow-incomplete
