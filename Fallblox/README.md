# Fallblox Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `00040000000B4F00/` → `sd:/luma/titles/00040000000B4F00/`

## Çalışma dosyaları

Düzenleme kaynağı: `ceviri/fallblox_tr.csv`.

Araç girişi: `araclar/fallblox_tool.py`. Komutları oyun klasöründe çalıştırın.

Oyunun EURen/İngilizce mesaj yuvası değiştirilir. Kontrol kodlarını ve satır sınırlarını koruyun.

## Klasörler

- `ceviri/`: Düzenlenecek çeviri verileri.
- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `belgeler/`: Kullanım ve teknik açıklamalar.
