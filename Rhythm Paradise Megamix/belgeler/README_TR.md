# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

TSV tablolarının Turkish alanlarını düzenleyin; TAG/END/PUA kodlarını koruyun. Hazır mesaj üretim girdileri ceviri/proje/source altındadır. Ana üretim aracı araclar/build_v22.py dosyasıdır.

Düzenleme kaynağı: `ceviri/proje/project/EUENmessage/pajama_sarc/arc/`.

Araç girişi: `araclar/rhm_tr_text_tool.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
