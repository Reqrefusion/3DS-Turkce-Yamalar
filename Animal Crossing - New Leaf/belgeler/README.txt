# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

Üretim için kendi oyununuzdan çıkarılmış Script ve Font girdileri gerekir. Komut: python araclar/build_patch.py --script <Script> --translations ceviri --font <Font> --out <cikti>.

Düzenleme kaynağı: `ceviri/`.

Araç girişi: `araclar/build_patch.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
