# Ever Oasis Türkçe Yama
https://github.com/rozenmad/ever_oasis_gmsg

Yukarıdaki lua kodu phytona dönüştürülmüştür. Kullanımı:

```
python araclar/oasis_gmsg.py import kaynaklar/main.gmsg ceviri/main_tr.md main_new.gmsg

python araclar/oasis_gmsg.py export kaynaklar/main.gmsg main.md
```

Yama Avrupa bölgesi içindir. 00040000001A4900 dosyasını sd kartdaki luma/titles klasörüne atın.

Çeviride hatalar bulursanız ceviri/main_tr.md üzerinden düzeltebilir veya issue açabilirsiniz. Yarcımcı olması adına diğer dillerde bakabilirsiniz.
