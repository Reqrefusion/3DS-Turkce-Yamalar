# IRONFALL Invasion Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen klasörü SD kartınızdaki `luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** seçeneğini etkinleştirin. Mevcut yamanızı değiştirmeden önce yedekleyin.

- `000400000015B100/` → `sd:/luma/titles/000400000015B100/`

Bu klasörde yeniden üretme aracı bulunmuyor. Kurulum dosyaları korunmuştur; oyun içi çalışma bu düzenleme sırasında denenmedi.
