# SUPER STREET FIGHTER Ⅳ 3D EDITION Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `0004000000033C00/` → `sd:/luma/titles/0004000000033C00/`

## Çalışma dosyaları

Düzenleme kaynağı: `calisma/texts/`.

Araç girişi: `araclar/sf4_tr_gui.py`. Komutları oyun klasöründe çalıştırın.

Metin ve grafik çalışma kaynakları calisma ağacında tutulur. GUI başlatıcısı araclar/GUI_AC.bat, temel biçim aracı araclar/sf4_tr_tool.py dosyasıdır. Hazır _eng ağacı Title ID altındaki romfs içinde bulunur.

## Klasörler

- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `calisma/`: Ara çıktılar ve çalışma kopyaları.

Kurulum ve çeviri dosyalarının içerikleri klasör düzenlemesi sırasında korunmuştur. Teknik denetim ile gerçek cihazdaki görünüm ayrı değerlendirilmelidir.
