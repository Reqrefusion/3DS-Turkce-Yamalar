# Zero Escape - Virtue's Last Reward Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `00040000000AEB00/` → `sd:/luma/titles/00040000000AEB00/`

## Çalışma dosyaları

Araç girişi: `araclar/verify_turkish_fonts.py`. Komutları oyun klasöründe çalıştırın.

Font ve Lua teşhis araçları araclar altındadır. apply_turkish_fonts_legacy.py mevcut hazır fontların yerine doğrudan uygulanmamalıdır. Gerçek oyun dosyalarıyla çalışmadan önce yedek alın.

## Klasörler
