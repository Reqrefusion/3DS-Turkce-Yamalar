# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

Kontrol: python araclar/main.py validate. Üretim ve font kontrolü için kendi temiz oyun girdiniz gerekir; araclar/ktl yardımcı pakettir.

Düzenleme kaynağı: `ceviri/Kirby_TR_translated.csv`.

Araç girişi: `araclar/main.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
