# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

Yeniden üretim için temiz EUR euenglish.res gerekir. Yardımcı kaynak tablolar ceviri altında, font girdileri araclar/FONT_METRIC_FIX altında tutulur.

Düzenleme kaynağı: `ceviri/translation_turkish_ready.csv`.

Araç girişi: `araclar/dkcr3d_tool_v4_safe.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
