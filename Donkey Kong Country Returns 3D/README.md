# Donkey Kong Country Returns 3D Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `00040000000CCF00/` → `sd:/luma/titles/00040000000CCF00/`

## Çalışma dosyaları

Düzenleme kaynağı: `ceviri/translation_turkish_ready.csv`.

Araç girişi: `araclar/dkcr3d_tool_v4_safe.py`. Komutları oyun klasöründe çalıştırın.

Yeniden üretim için temiz EUR euenglish.res gerekir. Yardımcı kaynak tablolar ceviri altında, font girdileri araclar/FONT_METRIC_FIX altında tutulur.

## Klasörler

- `ceviri/`: Düzenlenecek çeviri verileri.
- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `belgeler/`: Kullanım ve teknik açıklamalar.
