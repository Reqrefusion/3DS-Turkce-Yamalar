DKCR3D - TÜRKÇE ÇEVİRİ / NİHAİ QA SÜRÜMÜ

Bu paket, tüm dil sütunları karşılaştırılarak hazırlanan Türkçe yerelleştirmenin ayrıntılı ikinci kalite ve teknik QA turundan geçirilmiş sürümüdür.

Kontroller:
- 855/855 Türkçe metin satırı dolu.
- İngilizce, Fransızca, Almanca, İtalyanca ve İspanyolca sütunları bağlam/ton açısından karşılaştırıldı.
- Kontrol kodları, değişkenler ve özel etiketler korundu.
- Uzun UI metinlerinde satır kırımları gözden geçirildi.
- Cranky diyalogları, onay metinleri, bölüm/galeri/müzik adları ayrıca elden geçirildi.
- Türkçe karakterlerin font eşleme tablolarında bulunduğu doğrulandı.
- VAL/FNT/TEX teknik dosyaları kaynak arşivdeki halleriyle byte-byte korunmuştur.
- Haritadaki 1-D, 2-D ... 9-D kodları bilinçlidir: diğer diller de Shop harfini yerelleştirdiği için Türkçede D = Dükkân kullanılmıştır.
- (Returns) ibareleri müzik adı ayrımı için korunmuştur.

Not: Statik dosya QA'sı temizdir. Gerçek 3DS/emülatör ekranındaki piksel bazlı taşma ancak oyun içinde görsel testle kesinleştirilebilir.


Length review: UI text was re-audited comparatively against English/French/German/Italian/Spanish. Narrow labels were shortened or reflowed where appropriate; control codes and non-text assets remain unchanged.

Final comparative length QA: narrow UI labels were evaluated by both per-row official-language maxima and shared UI-family capacity; supported scale/squish tags were added only where official localizations show the same technique.
