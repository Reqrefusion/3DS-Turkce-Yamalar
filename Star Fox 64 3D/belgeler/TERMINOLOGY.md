# Terminoloji

Bu dosya PR'larla güncellenebilir. Amaç aynı kavramın oyun boyunca aynı Türkçe karşılığı kullanmasıdır.

| İngilizce / kavram | Tercih edilen Türkçe | Not |
|---|---|---|
| Charge Shot | Şarjlı Atış | Eğitim ve savaş metinlerinde tutarlı kullanın. |
| Barrel Roll | Varil Dönüşü | Eylem/komut bağlamına göre küçük harf kullanılabilir. |
| Boost | Hızlanma | Fiil olarak “hızlan” kullanılabilir. |
| Wing-repair item | Kanat Onarım Kiti | Arayüzde gerekirse kısaltılabilir. |
| Laser item / upgrade | Lazer Güçlendirmesi | Bağlama göre “lazer” yeterli olabilir. |
| Free Flight Mode | Serbest Uçuş Modu | Mod adı. |
| Score Attack | Skor Mücadelesi | Mod/menü bağlamında. |
| Sector X/Y/Z | X/Y/Z Sektörü | Özel bölüm adı biçimi. |
| Area 6 | Bölge 6 | Bölüm adı. |
| Corneria / Venom / Meteo | Değiştirme | Evren özel adları. |
| Arwing / Landmaster / Blue-Marine | Değiştirme | Araç özel adları. |

## Karakter tonu

- **Fox:** sakin, lider, kısa emirler.
- **Falco:** özgüvenli, alaycı; cümleleri fazla resmîleştirmeyin.
- **Slippy:** daha telaşlı/heyecanlı ama çocuklaştırmadan.
- **Peppy:** deneyimli, yol gösterici.
- **General Pepper:** resmî ve askerî.
- **Star Wolf:** rakip, meydan okuyan; kaynakta olmayan ağır argo eklemeyin.
