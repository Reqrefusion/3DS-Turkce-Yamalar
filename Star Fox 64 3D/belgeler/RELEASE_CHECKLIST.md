# Paket kontrol listesi

- [ ] Oyun klasöründe `python araclar/validate_translation.py` başarılı.
- [ ] Kendi temiz oyun girdisiyle üretim başarılı.
- [ ] Kaynak SHA-256 doğrulamaları ve ZIP bütünlük kontrolü başarılı.
- [ ] Kurulum ağacı `luma/titles/<TitleID>/romfs/Resources/` biçiminde.
- [ ] Açılış, menü, eğitim ve görevler oyun içinde kontrol edildi.
- [ ] Türkçe karakterler ve metin taşmaları gözle kontrol edildi.
- [ ] Terimler [terminoloji belgesiyle](TERMINOLOGY.md) tutarlı.
- [ ] Pakete özgün `Resources.zip` veya gereksiz oyun girdisi eklenmedi.

İşaretlenmemiş maddeler tamamlanmış test olarak değerlendirilmemelidir.
