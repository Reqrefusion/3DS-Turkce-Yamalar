# Katkı hazırlama

Bu oyun, ortak 3DS Türkçe yamalar deposunun bir klasörüdür. Ayrı depo oluşturmak gerekmez.

1. `ceviri/tr_TR.jsonl` içindeki Türkçe alanlarını düzenleyin.
2. Oyun klasöründe `python araclar/validate_translation.py` çalıştırın.
3. Görüntü sorunu varsa ilgili bölüm ve ekran görüntüsüyle açıklayın.
4. Değişikliklerinizi mevcut deponun katkı akışından gönderin.

Özgün `Resources.zip` veya ROM dosyalarını katkıya eklemeyin. Yerel doğrulama komutu çalıştırılmalıdır; otomatik kontrol kurulu olduğu varsayılmamalıdır.
