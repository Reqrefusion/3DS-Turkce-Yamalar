# GitHub'a İlk Yükleme

1. GitHub'da boş bir repo oluşturun.
2. Bu paketin içeriğini repo köküne kopyalayın.
3. `AUTHORS.md` içindeki proje sahibi satırını GitHub adınızla güncelleyin.
4. İsterseniz `LICENSES/TRANSLATION_NOTICE.md` içindeki çeviri lisansı tercihini netleştirin.
5. İlk commit öncesi `python scripts/validate_translation.py` çalıştırın.
6. GitHub'da Issues ve Actions özelliklerini açık bırakın.

Önerilen repo açıklaması:

> Star Fox 64 3D için topluluk destekli Türkçe yerelleştirme projesi. Çeviri verisi, MSBT araçları ve Luma3DS yama oluşturucu.

Önerilen topic'ler: `star-fox-64-3d`, `turkish-translation`, `localization`, `3ds`, `luma3ds`, `msbt`, `fan-translation`.
