# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

CSV kontrol etiketlerini koruyun. Kurulum için yalnız kökteki Title ID ağacı gerekir.

Düzenleme kaynağı: `ceviri/fullblox_tr.csv`.

Araç girişi: `araclar/fullblox_tool.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
