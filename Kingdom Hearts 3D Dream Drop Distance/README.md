# Kingdom Hearts 3D Dream Drop Distance Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `0004000000095500/` → `sd:/luma/titles/0004000000095500/`

## Çalışma dosyaları

Düzenleme kaynağı: `ceviri/translations_aligned_tr_complete.csv`.

Araç girişi: `araclar/kh3d_message_tool.py`. Komutları oyun klasöründe çalıştırın.

Yalnız translation alanını düzenleyin. Fransızca hedef dil yuvasını ve kayıt kimliklerini koruyun. Özgün RBIN girdileri kaynaklar altındadır.

## Klasörler

- `ceviri/`: Düzenlenecek çeviri verileri.
- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `kaynaklar/`: Üretimde gereken girdiler ve referanslar.
- `belgeler/`: Kullanım ve teknik açıklamalar.
