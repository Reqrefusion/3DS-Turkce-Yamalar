# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

Font çalışma girdileri ve font aracı araclar/font_tool altındadır. Metin kapasitesi ve kontrol işaretleri korunmalıdır.

Düzenleme kaynağı: `ceviri/fe_multilang.csv ve ceviri/tweaker_multilang.csv`.

Araç girişi: `araclar/lm2_localizer.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
