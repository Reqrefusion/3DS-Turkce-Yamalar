# Luigi's Mansion 2 Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `0004000000076500/` → `sd:/luma/titles/0004000000076500/`

## Çalışma dosyaları

Düzenleme kaynağı: `ceviri/fe_multilang.csv` ve `ceviri/tweaker_multilang.csv`.

Araç girişi: `araclar/lm2_localizer.py`. Komutları oyun klasöründe çalıştırın.

Font çalışma girdileri ve font aracı araclar/font_tool altındadır. Metin kapasitesi ve kontrol işaretleri korunmalıdır.

## Klasörler

- `ceviri/`: Düzenlenecek çeviri verileri.
- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `belgeler/`: Kullanım ve teknik açıklamalar.
