# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

EUR oyun güncellemesi 4.1 hedeflenir; güncelleme Title ID değeri 0004000E0017C900. Oyunu English başlatın. Eski global_free.pak override dosyalarıyla karıştırmayın. Araç kaynak hash değerlerini denetler.

Araç girişi: `araclar/shovel_knight_3ds_v41_tr_tool.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
