# Shovel Knight Treasure Trove Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `000400000017C900/` → `sd:/luma/titles/000400000017C900/`

## Çalışma dosyaları

Araç girişi: `araclar/shovel_knight_3ds_v41_tr_tool.py`. Komutları oyun klasöründe çalıştırın.

EUR oyun güncellemesi 4.1 hedeflenir; güncelleme Title ID değeri 0004000E0017C900. Oyunu English başlatın. Eski global_free.pak override dosyalarıyla karıştırmayın. Araç kaynak hash değerlerini denetler.

## Klasörler

- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `belgeler/`: Kullanım ve teknik açıklamalar.
