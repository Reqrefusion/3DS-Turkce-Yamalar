# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

Grafik çeviri kayıtları varliklar altında, metin tablosu ve sözlük ceviri altındadır. Kontrol belirteçlerini koruyun.

Düzenleme kaynağı: `ceviri/merino.msbt.TR.final.csv`.

Araç girişi: `araclar/yww_csv_tool.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
