# Pokémon Moon Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `0004000000175E00/` → `sd:/luma/titles/0004000000175E00/`

Yama **PunpunElla (Arda Çabuk)** tarafından hazırlanmıştır; burada arşivlenmektedir. Oyun içinde çalışması bu düzenlemede denenmedi.

[Kaynak ve katkı bilgisi](https://forum.donanimhaber.com/pok-mon-moon-turkce-yama-3ds-citra-azahar--164133076)

Bu klasörde ayrı bir çeviri düzenleme veya yeniden üretme aracı bulunmuyor. Hazır kurulum içeriği korunmuştur.
