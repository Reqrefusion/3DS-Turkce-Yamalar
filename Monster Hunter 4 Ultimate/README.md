# Monster Hunter 4 Ultimate Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `0004000000126300/` → `sd:/luma/titles/0004000000126300/`

## Çalışma dosyaları

Düzenleme kaynağı: `ceviri/MH4_Ceviri_TR_SAFE_DONOR_v130.csv`.

Araç girişi: `araclar/mh4_lmd_tool_v3.py`. Komutları oyun klasöründe çalıştırın.

USA hedefi ve oyun güncellemesi 1.3.0 gereksinimi korunmalıdır. Update Title ID: 0004000E00126300. code.ips yalnız doğrulanan oyun girdisine aittir; farklı executable üzerinde kullanılmamalıdır. Kayıt dosyasını silmeyin.

## Klasörler

- `belgeler/`: Kullanım ve teknik açıklamalar.
