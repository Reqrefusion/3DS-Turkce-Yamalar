# Tomodachi Life Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `000400000008C400/` → `sd:/luma/titles/000400000008C400/`

## Çalışma dosyaları

Düzenleme kaynağı: `ceviri/`.

Araç girişi: `araclar/tomodachi_tr_tool.py`. Komutları oyun klasöründe çalıştırın.

Ana metin proje ağacı ceviri altındadır. Düzenleyici için araclar/run_windows.bat kullanılabilir; tomodachi_formats.py yardımcı modüldür.

## Klasörler

- `ceviri/`: Düzenlenecek çeviri verileri.
- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `belgeler/`: Kullanım ve teknik açıklamalar.
