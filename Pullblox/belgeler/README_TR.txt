# Çalışma akışı

Kurulum için kökteki README.md dosyasını kullanın. Title ID klasörleri oyun kökünde tutulur.

İngilizce mesaj yuvası hedeflenir. calisma/kurulum_kopyasi yalnız yardımcı çıktı kopyasıdır; kurulumda kökteki Title ID ağacını kullanın.

Düzenleme kaynağı: `ceviri/pullblox_tr.csv`.

Araç girişi: `araclar/pullblox_tool.py`. Komutları oyun klasöründe çalıştırın; ayrıntılı seçenekler ilgili aracın yardımında bulunur.

Çeviri kimliklerini ve kontrol kodlarını koruyun. Özgün girdilerin üzerine yazmayın. Teknik doğrulama, gerçek cihaz testi yerine geçmez.
