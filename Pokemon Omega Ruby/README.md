# Pokemon Omega Ruby Türkçe yama

## Kurulum

Oyununuzun Title ID değeriyle eşleşen kök klasörü `sd:/luma/titles/` içine kopyalayın. Luma3DS ayarlarında **Enable game patching** açık olmalıdır. Mevcut yamanızı önce yedekleyin.

- `000400000011C400/` → `sd:/luma/titles/000400000011C400/`

## Çalışma dosyaları

Düzenleme kaynağı: `ceviri/01_Text_Set_A.tsv` ve `ceviri/02_Text_Set_B.tsv`.

Araç girişi: `araclar/ORAS_TR_Text_Tool.py`. Komutları oyun klasöründe çalıştırın.

Arayüzü açmak için araclar/BASLAT.bat kullanılabilir. Kimlik ve kontrol alanlarını koruyun.

## Klasörler

- `ceviri/`: Düzenlenecek çeviri verileri.
- `araclar/`: Üretim, düzenleme ve doğrulama araçları.
- `belgeler/`: Kullanım ve teknik açıklamalar.
