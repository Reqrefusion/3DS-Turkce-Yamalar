FIRE EMBLEM AWAKENING TÜRKÇE YAMA — PASS 202
=============================================

HEDEF
-----
Bu paket, verdiğiniz çok-dilli PAL/EUR kaynak yapısındaki U (English) dil slotunu
Türkçe Pass 202 metinleriyle değiştirir ve Türkçe karakter fontlarını içerir.

HAZIR YAMA
----------
romfs/
  m/U/       -> 854 Türkçeleştirilmiş .bin.lz
  fonts/     -> 6 Türkçeleştirilmiş .bfnt.lz

3DS / LUMA (EUR)
----------------
Paket içindeki:
  Luma_EUR_SD_ROOT/luma/

klasörünü SD kartın köküne birleştirin.

Son yol:
  /luma/titles/000400000009F100/romfs/m/U/
  /luma/titles/000400000009F100/romfs/fonts/

Luma yapılandırmasında "Enable game patching" açık olmalıdır.

EMÜLATÖR / ÇIKARILMIŞ ROMFS
----------------------------
Paketin kökündeki "romfs" klasörünü oyunun mod/romfs dizinine birleştirin.
Mevcut RomFS'yi elle düzenliyorsanız:
  romfs/m/U/*      -> oyunun m/U klasörü
  romfs/fonts/*    -> oyunun fonts klasörü

NOTLAR
------
- Bu hazır yapı PAL/EUR kaynağa göredir.
- Çeviri Pass 202 CSV'lerinden yeniden enjekte edilmiştir.
- Mesaj arşivi yeniden açılarak 854 dosya / 15.817 kayıt doğrulanmıştır.
- 6 Türkçe font dosyası dahildir.
- Kaynakta boş olan metinler boş kalır; yalnız işaret/tepki olan 16 satır
  kaynak biçimiyle korunur.
